Code of Conduct
================

pyGearBox is committed to fostering a welcoming and inclusive community. To ensure a positive experience for all contributors and users, we have established the following Code of Conduct.

1. **Be Respectful:** Treat all individuals with respect and kindness. Harassment, discrimination, or any form of abusive behavior will not be tolerated.

2. **Be Inclusive:** We welcome and encourage participation from everyone, regardless of their background or identity. Diverse perspectives make our community stronger.

3. **Communicate Openly:** Share your thoughts, ideas, and feedback openly and constructively. Be receptive to feedback from others.

4. **Collaborate:** Work together with others to achieve common goals. Be willing to help and support your fellow contributors.

5. **Report Issues:** If you encounter any behavior that violates this Code of Conduct, please report it to the project maintainers.

By participating in the pyGearBox community, you agree to abide by this Code of Conduct. Thank you for helping us create a positive and inclusive environment!
For any questions or concerns regarding this Code of Conduct, please contact the project maintainers.
